# Curated images

Copied from `old-site/images/media-images` by `_copy_images.py`.

The WordPress dump has 618 files. Most are duplicates, placeholders, theme leftovers, AI generations, or event posters. This folder is the set the site is allowed to use.

If you add a photo:

1. Prefer a real photograph of the community, the hall, or the monks.
2. Give it a descriptive filename.
3. Add it to `_copy_images.py` so a later refresh does not lose the mapping.
4. Do not copy `ChatGPT*`, `Gemini*`, `placeholder*`, `Home_Interior_Design*`, or screenshots.
